# Craft Heritage Archive

A community archive of local and traditional handicrafts (hand-woven carpets, kilims, pottery and more). Users add crafts they know, others add how they are made, and everyone can follow contributors and search by craft type and region.

Non-commercial: no selling, no auctions, no payments.

SWE 573 individual project, Boğaziçi University.

Installation instructions will be added with the first release.
